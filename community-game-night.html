Best first community night

Codenames in Discord

Start here when you want the least friction. The official free Codenames Activity opens directly inside Discord, so the group can stay together in the voice channel without buying or installing a separate game.

First choice · team word game

Codenames

Free and available directly as a Discord Activity. Divide into two teams, keep conversation in voice, and use the in-channel game board.

Small group · quiet strategy

Ticket to Ride

Best when 3–5 people want a calmer strategy table. Board Game Arena runs in a browser for 2–5 players with no download. The official digital app also supports friend games through Bubble accounts; Nintendo lists 1–5 players for the Switch Deluxe Edition.

Party night · phones as controllers

Jackbox

Only the host needs to buy and install a Party Pack. Everyone else joins at jackbox.tv with the room code, using a phone or browser as the controller while the host shares the game screen in Discord.

Large group · social deduction

Blood on the Clocktower

Choose this for a longer event centered on debate, persuasion, and reading the room. It needs a prepared Storyteller to run the game and teach the roles, so schedule it rather than launching it spontaneously.
